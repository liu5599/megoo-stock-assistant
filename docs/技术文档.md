## 1. 项目概述

将「选股演示工具」升级为具备**职业私募基金经理操盘能力**的量化投资助手。
融合指南针炒股软件（资金流/三维决策/估值空间/仓位控制）、容维题材宝典（题材挖掘/情绪股）与
Quant 量化分析师视角，形成完整操盘闭环：

```
判大势(温度+Quant) → 辨多空(资金) → 挖热点(题材) → 定买卖(三维决策+交易计划)
→ 定风险区(估值+威科夫) → 调仓位(风控) → 验证(回测) → AI日报(PushPlus推送)
```

**技术栈**：Python 3.11 · FastAPI · Jinja2 · akshare/baostock/tushare · Vue3+Vant4+Capacitor（手机端）· SQLite

## 3. 分析引擎详解

### 3.1 市场温度计 `market_temperature.py`
- **输入**：乐咕市场活跃度（涨跌/涨停/跌停家数）+ 成交额 + 上证50历史PE
- **公式**：温度 = 情绪×0.4 + 量能×0.2 + 估值×0.4
- **输出**：0-100 温度 + 三区（安全边界区<40 / 价值中枢区40-70 / 风险警戒区>70）+ 操作建议
- 估值分位越低 → 温度越低 → 越安全

### 3.2 Quant 量化分析 `quant_analytics.py`
| 功能 | 方法 | 输出 |
|---|---|---|
| 市场画像 | `market_snapshot()` | 8大指数 20/60/250日收益 + 年化波动 + 平均相关性 + 市场状态判定 |
| 风格轮动 | `style_rotation()` | 大盘vs小盘、成长vs价值 相对强弱 + 轮动信号 |
| 风险状态 | `risk_regime()` | 20/60/120日波动率 + 波动聚集比 + 250日最大回撤 |
| 组合风险 | `portfolio_risk()` | VaR95/99（历史模拟）+ 夏普 + 最大回撤 + 相关性矩阵 |

### 3.3 题材中心 `theme_center.py`
- **新题材**：新浪概念资金流（涨幅+净流入+领涨股）
- **热题材**：涨停池行业分布（涨停数+热度评分）
- **情绪个股**：涨停池首板/连板/炸板标记 + 情绪龙头识别
- **降级链**：新浪概念 → 涨停池行业分布（东财被风控时自动切换）

### 3.4 资金追踪 `money_flow.py`
- 主力榜（今日/3日/5日）+ 敢死队（涨停+高换手+主力流入）+ 龙虎榜 + 多空对比
- **降级链**：东财直连(push2delay) → Tushare → akshare → 龙虎榜降级

### 3.5 三维决策 `decision_signals.py`
| 维度 | 指标 | 信号 |
|---|---|---|
| 长线 | 周线 MA20/MA60 排列 + 月线方向 | 多/空/观望 |
| 波段 | 日线 MACD 金叉死叉 + BOLL + KDJ | 多/空/观望 |
| 短线 | 5日动量 + 量比 + 短期均线 + RSI | 多/空/观望 |

综合分 = 长线×0.4 + 波段×0.35 + 短线×0.25

### 3.6 估值空间 `valuation_space.py`
- 8年 PE(TTM)/PB 历史分位 → 三区：安全边界区(<20%) / 价值中枢区(20-70%) / 风险警戒区(>70%)
- **数据源**：Tushare daily_basic（付费）→ 东财 stock_value_em（免费）

### 3.7 威科夫吸筹引擎 `wyckoff.py`（学自「老猫与指标」）
- **吸筹区间识别**：横盘 + 缩量 + 振幅收窄
- **Spring 弹簧测试**：跌破区间下沿快速收回 = 教科书抄底点（评级提升一档）
- **SOS 强势信号**：放量突破区间上沿 = 主升启动
- 量价行为评分（放量滞涨=派发 / 缩量回调=吸筹）

### 3.8 交易计划引擎 `trade_planner.py`
对每只股票输出完整操盘计划：
```
评级 S/A/B/C（多周期共振+估值+威科夫）
入场区间 / 目标价(2:1盈亏比) / 止损价(ATR/均线/支撑)
仓位%(凯利+风险平价) / 单笔风险≤2% / 持有周期 / 操作逻辑 / 风险提示
组合层：市场温度 → 总仓位建议（20-40% / 40-60% / 60-80%）
```

### 3.9 动态选股引擎 `dynamic_screener.py`
- 情绪周期：涨停家数/连板高度/炸板率 → 风险偏好
- 题材轮动：今日涨停行业 vs 昨日 → 新晋主线
- 底部吸筹池：龙虎榜当日下跌但净买大 = 资金低位建仓
- 主线龙头池：连板高度 + 封板资金

### 5.2 东财限频突破（data/eastmoney_direct.py）
1. **备用节点 push2delay**（主节点 502 时可用，实测有效）
2. **Cookie 预热**：先访问首页拿 cookie 再请求 API
3. **域名轮换**：push2delay → push2 → push2his
4. **限速**：请求间隔 0.6s

### 5.3 SWR 缓存（analysis/_cache.py）
- 过期立即返回旧数据 + 后台线程刷新（用户永远秒开）
- TTL：行情 5min / 指数K线 30min / 估值 1h
- 结果持久化 `cache_data/ops_overview.json`（重启秒回）

### 5.4 熔断机制
- 东财接口连续失败 → 熔断开启 → 后续请求直接走降级源
- 单次进程内有效
